# Ranger Home updates

`catalog.json` tells Ranger Home's Blender add-ons (Cabinet Tools, CAD Draft, Ranger Design Studio)
about their latest versions and the content packs available. The add-ons read it at most once a day,
only with Blender's Allow Online Access on: https://miker6219.github.io/ranger-updates/catalog.json

It holds versions, pack names and store links only, no code. Its source is `packs/catalog.json` in the
Ranger Design Studio repository; edit it there and publish it here.
